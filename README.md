# Sports Leagues Explorer

A simple React + TypeScript app for browsing sports leagues. Users can search leagues by name, filter by sport, and expand cards to view league badges.

## Project structure

- `src/App.tsx` contains the main app layout and filtering logic.
- `src/components/` contains the UI pieces for search, filters, and league cards.
- `src/hooks/` contains the data-fetching logic for leagues and badges.
- `src/index.css` contains the app styling.

## Run locally

Start the development server with:

```bash
npm run dev
```
